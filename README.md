LocalWeather
HTML, CSS ve JavaScript kullanılarak geliştirilmiş, minimalist ve kullanıcı dostu bir hava durumu uygulaması. Kullanıcının anlık konumuna göre veya aratılan şehre göre gerçek zamanlı veriler sunar.

Özellikler
Otomatik Konum Tespiti: Tarayıcı üzerinden konum izni alarak bulunduğunuz ilçenin/şehrin hava durumunu anında gösterir.

Şehir Arama: Dünyadaki herhangi bir şehrin hava durumu verilerine manuel arama ile ulaşılabilir.

Detaylı Veriler: Sıcaklık (°C), nem oranı (%) ve rüzgar hızı (km/h) bilgilerini içerir.

Dinamik Arayüz: Hava durumuna göre değişen ikonlar ve modern "Glassmorphism" tasarımı.

Responsive Tasarım: Mobil cihazlar, tabletler ve masaüstü bilgisayarlarla tam uyumlu.

Kullanılan Teknolojiler
HTML5: Yapısal iskelet.

CSS3: Modern tasarım ve cam efekti (Glassmorphism).

JavaScript (ES6+): Fetch API, Geolocation API ve DOM Manipülasyonu.

API: OpenWeatherMap API
